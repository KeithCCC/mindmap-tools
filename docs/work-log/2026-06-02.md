## Summary

- Continued the mindmap brainstorming app by replacing the basic tree surface with a focused Mind Elixir editing experience.

## Completed Work

- Integrated Mind Elixir as the primary visual mind tree editor.
- Added compact app layout changes to maximize the brainstorming pane and make the right property inspector collapsible.
- Added app-owned keyboard behavior:
  - `F2` starts inline editing for the selected node.
  - `Tab` creates a child node.
  - `Enter` creates a sibling node.
  - Arrow keys move selection through parent, child, and sibling relationships.
  - `Delete` / `Backspace` delete non-root selected nodes.
- Added a persistent selected-node highlight so users can see the active node after inline edits and keyboard navigation.
- Fixed inline edit cleanup by separating the React overlay from the Mind Elixir-owned DOM container.
- Added Mind Elixir conversion helpers and tests.
- Improved Excalidraw export/import round-tripping by preserving app metadata and syncing edited Excalidraw text labels back into the canonical document.
- Added top-level `Export Excalidraw` action.
- Added native data controls:
  - `Save Data` exports the internal mindmap document as `mindmap-tools.json`.
  - `Load Data` restores a saved native JSON document.
  - `Reset Data` starts a fresh `Brainstorm` document.
- Kept browser persistence through `localStorage` and added tests for it.
- Removed the unused Playwright dev dependency that had been added during earlier keyboard testing.
