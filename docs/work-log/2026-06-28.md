## Completed Work

- Improved keyboard-driven mindmap editing:
  - `Tab` creates a child and immediately starts inline editing.
  - `Ctrl+Enter` inserts an intermediate node before the selected node.
  - Delete removes only the selected node, promotes its children, and returns selection to the parent.
  - Selection/focus indication is preserved after inline editing.
- Added local mindmap file workflow:
  - Map file name is separate from the root node title.
  - JSON download/save/load/reset controls are available.
  - Browser local persistence remains enabled.
- Hid Neon cloud storage controls from the UI while keeping the implementation commented for future work.
- Added Excalidraw export support and strengthened Mind Elixir conversion behavior.
- Added right-click node color selection.
- Added semantic outline improvements:
  - Floating, larger outline window.
  - Collapse all / expand all and per-node collapse toggles.
  - Drag/drop outline reorder and move-under-root support.
  - Explicit Up/Down sibling ordering controls so nodes such as `FMI` can be moved above `Personal` without precise dragging.
- Expanded unit and UI coverage for tree operations, outline reorder, deletion behavior, inline edit behavior, hidden Neon controls, and file workflows.
